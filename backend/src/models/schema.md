# LearnCamp Domain Models

- **User**: trainer or student with JWT auth identity.
- **Bootcamp**: training program owned by one trainer.
- **LiveSession**: scheduled real-time class attached to a bootcamp.
- **ChatMessage**: session chat entries for live and async discussion.
- **Resource**: downloadable document or file per bootcamp.
- **Replay**: recorded video metadata per session.
- **Payment**: Mobile Money transaction proving enrollment access.
